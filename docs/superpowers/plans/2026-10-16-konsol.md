# Konsol — implementeringsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** En PWA, der gør en telefon med HDMI til en spillekonsol for 2–10 spillere med telefoner (WebRTC) og op til 4 Bluetooth-controllere, med Sumo på isflagen som første spil.

**Architecture:** Statisk site i `public/` (ES-moduler, import map, ingen byggekæde) med to sider: konsollen (`index.html`) og controlleren (`c.html`). En lille Node-signalserver uden afhængigheder (`server/`) formidler WebRTC-håndtrykket og videresender input som reserve. Input fra alle kilder samles i én spillerliste, som spilmoduler i `public/src/games/<id>/` læser. Ren logik (server, spillerliste, lobby, sumo-fysik og -regler) testes med `node --test`; browserdelen med en ende-til-ende-test i headless Chrome.

**Tech Stack:** Node 24 (dev) / node:22-alpine (container), three.js 0.169, qrcode-generator 2.0.4 (vendoret), puppeteer-core (kun e2e), WebRTC, WebSocket (RFC 6455, egen implementering kopieret fra Tinsoldat).

**Spec:** `docs/superpowers/specs/2026-10-16-konsol-design.md`

## Global Constraints

- Al tekst, spilleren ser, er på dansk.
- Ingen byggekæde: ES-moduler + import map; three.js og qrcode kopieres ind i `public/vendor/` af `sync-vendor.sh` (git-ignoreret af `../.gitignore`).
- Kildekoden til browseren ligger i `public/src/` (som Kattekaos), ikke `src/` — det er det, specens `src/…` betyder, når der ingen byggekæde er.
- Signalserveren: kun Node-builtins. Grænser: 10 controllere pr. rum, beskeder ≤ 4 KB, ≤ 100 rum, rum uden konsol nedlægges efter 60 s, `ORIGINS` tjekkes.
- Højst 10 spillere i alt (telefoner + controllere + bots); højst 4 gamepads (browserens loft).
- Input: `{s, x, y, a, b}`, 30 Hz + straks ved knapskift; dødzone 0,12, cirkel-klippet; 1 s uden input → pind 0 og "tabt".
- WebRTC uden STUN/TURN (`iceServers: []`); kanalerne `in` (`ordered:false, maxRetransmits:0`) og `ctl` (pålidelig).
- Dev-server på port 8091 med pid-fil `server.pid`. **Brug aldrig `pkill -f "node server.js"`** — luk på pid.
- Signal-containeren lytter på `127.0.0.1:3260` på `10.0.1.198` (ledig, tjekket 2026-10-16).
- Asset-serveren (GPU) er optaget til og med 2026-10-18: ingen jobs i denne plan.
- Commit-beskeder slutter med de to attribution-linjer fra sessionen.

## Afvigelser fra spec'en (bevidste, små)

1. **Menu og lobby er én skærm.** En telefon kan ikke styre en menu, før den har sluttet sig til, så QR-koden, spillerpladserne og spilvalget står på samme skærm. Spillet vælges med pinden (eller et tryk på kortet), A = klar.
2. **Reserven slår til med det samme, ikke efter 3 s.** Indtil datakanalen er åben, går input via WebSocket; når den åbner, skifter controlleren selv. Løbenummeret `s` fjerner dubletter. Det er strengt bedre end at vente 3 s uden input.
3. **Controller-siden er `c.html?g=KODE`** (en statisk filserver kan ikke `/c`).
4. **Flagen krymper glidende** (0,1 m/s fra 20 s, ned til 2,4 m) i stedet for i trin — så det, man ser, altid er det, fysikken bruger.

## Review Focus

1. En telefon går i dvale eller skifter app midt i en runde → dyret står stille, spilleren vises som tabt, og når telefonen kommer tilbage, er det samme plads og farve. (Task 1: samme `pid` genbruger peer-nummer; Task 2: stale + genforbindelse.)
2. Et hurtigt tryk på A (ned og op mellem to frames) skal tælle. (Task 2: latch-test.)
3. Konsollen genindlæses i lobbyen → samme kode, controllerne kommer tilbage af sig selv. (Task 1: host genoptager kode og får `peer-join` for dem, der venter.)
4. En anden konsol (fane) med samme gemte kode må ikke stjæle rummet. (Task 1: optaget kode giver ny kode.)
5. To dyr falder i samme frame, så ingen er tilbage → uafgjort, intet point, intet nedbrud. (Task 4: regel-test.)

Navne med HTML (`<b>`) må ikke blive til markup: serveren fjerner `<>` (Task 1-test), og al DOM-indsættelse går gennem `esc()` (Task 5).

### Task 1: Hus, signalserver og dev-server

**Files:**
- Create: `package.json`, `sync-vendor.sh`, `server.js`, `server/ws.mjs` (kopi), `server/signal.mjs`
- Test: `test/server.test.js`

**Interfaces:**
- Produces: `createSignal({origins, limits}) → { handleUpgrade(req, socket, head), rooms, stop() }`, `createSignalServer(opts) → http.Server`, `CODE_RE`, `LIMITS`, `cleanName(s)`.
- Protokol (JSON-tekst):
  - konsol → server: `{t:'host', code?}` → `{t:'room', code}`; derefter `{t:'peer-join', peer, pid, name}` / `{t:'peer-leave', peer}` / `{t:'signal'|'relay', from, data}`.
  - controller → server: `{t:'join', code, name, pid}` → `{t:'joined', peer, code, host:boolean}`; derefter `{t:'signal'|'relay', data}`, `{t:'host-gone'}`, `{t:'host-back'}`.
  - konsol sender `{t:'signal'|'relay', to: peer, data}`; controller sender `{t:'signal'|'relay', data}`.
  - fejl: `{t:'error', error: 'no-room'|'full'|'bad-name'|'bad-message'|'busy'}`.

```js
      const inbox = [], waiters = [];
      ws.on('message', (d) => {
        const m = JSON.parse(d);
        const i = waiters.findIndex((w) => w.pred(m));

      });
      const c = {
        ws,
        send: (m) => ws.send(typeof m === 'string' ? m : JSON.stringify(m)),
        next(pred = () => true, ms = 1000) {
          const i = inbox.findIndex(pred);
          if (i >= 0) return Promise.resolve(inbox.splice(i, 1)[0]);

            const w = { pred, resolve };

      };

      return c;
```

```js
// Konsollens signalserver (spec 2026-10-16, *Netværk*): rum pr. kode med én konsol og op til 10 controllere. Den
// videresender WebRTC-håndtrykket (signal) og, som reserve, input og beskeder (relay) uden at læse dem. Den husker
// intet på disk; en genstart lukker rummene, og konsol og controllere forbinder selv igen. Kun Node-builtins.
import http from 'node:http';
import { randomInt } from 'node:crypto';
import { realpathSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { acceptUpgrade, CLOSE } from './ws.mjs';

export const LIMITS = {
  pads: 10,               // controllere (telefoner) i ét rum
  pids: 50,               // forskellige telefoner, et rum husker i sin levetid
  rooms: 100,
  maxMessage: 4096,       // et SDP-tilbud til en datakanal er ~600 bytes
  rate: 120,              // beskeder pr. sekund pr. forbindelse: 30 Hz input + knapskift + håndtryk
  hostGoneMs: 60_000,     // så længe venter et rum på, at konsollen kommer tilbage
  pingMs: 20_000,
  idleMs: 45_000,
};
export const PATH = '/ws';
export const HEALTH = '/health';
export const NAME_MAX = 12;
const ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZ';     // intet I eller O: læses højt i stuen
export const CODE_RE = /^[A-HJ-NP-Z]{4}$/;
const PID_RE = /^[A-Za-z0-9_-]{8,32}$/;

export const cleanName = (s) => String(s ?? '').replace(/[\u0000-\u001f\u007f<>]/g, '').trim().slice(0, NAME_MAX);

export function createSignal({ origins = [], limits: over = {} } = {}) {
  const limits = { ...LIMITS, ...over };
  const rooms = new Map();
  const conns = new Set();

  const send = (conn, msg) => { if (conn?.open) conn.send(JSON.stringify(msg)); };
  const fail = (conn, error) => send(conn, { t: 'error', error });

  function newCode() {
    for (let i = 0; i < 1000; i++) {
      let c = '';
      for (let j = 0; j < 4; j++) c += ALPHABET[randomInt(ALPHABET.length)];
      if (!rooms.has(c)) return c;
    }
    return null;
  }

  function closeRoom(room) {
    clearTimeout(room.hostGoneTimer);
    rooms.delete(room.code);
    for (const p of room.pads.values()) {
      p.conn.room = null;
      fail(p.conn, 'no-room');
      p.conn.close(CLOSE.NORMAL, 'room closed');
    }
  }

  function host(conn, msg) {
    if (conn.role) return fail(conn, 'bad-message');
    let room = CODE_RE.test(msg.code) ? rooms.get(msg.code) : null;
    if (room?.host) room = null;                 // en anden konsol har koden: denne får en ny
    if (!room) {
      if (rooms.size >= limits.rooms) return fail(conn, 'busy');
      const code = CODE_RE.test(msg.code) && !rooms.has(msg.code) ? msg.code : newCode();
      if (!code) return fail(conn, 'busy');
      room = { code, host: null, pads: new Map(), pids: new Map(), nextPeer: 1, hostGoneTimer: null };
      rooms.set(code, room);
    }
    clearTimeout(room.hostGoneTimer);
    room.host = conn;
    conn.role = 'host';
    conn.room = room;
    send(conn, { t: 'room', code: room.code });
    for (const [peer, p] of room.pads) {
      send(conn, { t: 'peer-join', peer, pid: p.pid, name: p.name });
      send(p.conn, { t: 'host-back' });
    }
  }

  function join(conn, msg) {
    if (conn.role) return fail(conn, 'bad-message');
    const room = rooms.get(String(msg.code ?? '').toUpperCase());
    if (!room) return fail(conn, 'no-room');
    const name = cleanName(msg.name);
    if (!name) return fail(conn, 'bad-name');
    if (!PID_RE.test(String(msg.pid ?? ''))) return fail(conn, 'bad-message');
    let peer = room.pids.get(msg.pid);
    const old = peer !== undefined ? room.pads.get(peer) : null;
    if (old) {
      old.conn.room = null;                      // dens 'close' må ikke melde spilleren væk
      old.conn.close(CLOSE.NORMAL, 'replaced');
    } else if (room.pads.size >= limits.pads) {
      return fail(conn, 'full');
    }
    if (peer === undefined) {
      if (room.pids.size >= limits.pids) return fail(conn, 'full');
      peer = room.nextPeer++;
      room.pids.set(msg.pid, peer);
    }
    room.pads.set(peer, { conn, pid: msg.pid, name });
    conn.role = 'pad';
    conn.room = room;
    conn.peer = peer;
    send(conn, { t: 'joined', peer, code: room.code, host: !!room.host });
    send(room.host, { t: 'peer-join', peer, pid: msg.pid, name });
  }

  function forward(conn, msg) {
    const room = conn.room;
    if (!room) return fail(conn, 'bad-message');
    if (conn.role === 'host') {
      const p = room.pads.get(msg.to);
      if (p) send(p.conn, { t: msg.t, data: msg.data });
    } else {
      send(room.host, { t: msg.t, from: conn.peer, data: msg.data });
    }
  }

  function leave(conn) {
    conns.delete(conn);
    const room = conn.room;
    if (!room) return;
    conn.room = null;
    if (conn.role === 'host') {
      room.host = null;
      for (const p of room.pads.values()) send(p.conn, { t: 'host-gone' });
      room.hostGoneTimer = setTimeout(() => closeRoom(room), limits.hostGoneMs);
      room.hostGoneTimer.unref?.();
    } else if (room.pads.get(conn.peer)?.conn === conn) {
      room.pads.delete(conn.peer);
      send(room.host, { t: 'peer-leave', peer: conn.peer });
    }
  }

  function onConnection(conn) {
    conns.add(conn);
    conn.role = null;
    conn.room = null;
    conn.win = 0;
    conn.winStart = Date.now();
    conn.on('message', (raw) => {
      const now = Date.now();
      if (now - conn.winStart >= 1000) { conn.winStart = now; conn.win = 0; }
      if (++conn.win > limits.rate) return;      // for mange: smides væk, forbindelsen lever
      let msg;
      try { msg = JSON.parse(typeof raw === 'string' ? raw : raw.toString('utf8')); } catch { return fail(conn, 'bad-message'); }
      if (!msg || typeof msg !== 'object') return fail(conn, 'bad-message');
      try {
        if (msg.t === 'host') host(conn, msg);
        else if (msg.t === 'join') join(conn, msg);
        else if (msg.t === 'signal' || msg.t === 'relay') forward(conn, msg);
        else fail(conn, 'bad-message');
      } catch { fail(conn, 'bad-message'); }
    });
    conn.on('close', () => leave(conn));
  }

  function handleUpgrade(req, socket, head) {
    const { pathname } = new URL(req.url, 'http://x');
    if (pathname !== PATH) { socket.destroy(); return; }
    if (origins.length && !origins.includes(req.headers.origin)) {
      socket.write('HTTP/1.1 403 Forbidden\r\nConnection: close\r\nContent-Length: 0\r\n\r\n');
      socket.destroy();
      return;
    }
    const conn = acceptUpgrade(req, socket, head, { maxMessage: limits.maxMessage });
    if (conn) onConnection(conn);
  }

  const timer = setInterval(() => {
    const now = Date.now();
    for (const c of conns) { if (now - c.lastSeen > limits.idleMs) c.terminate(); else c.ping(); }
  }, limits.pingMs);
  timer.unref?.();

  return {
    handleUpgrade,
    rooms,
    stop() { clearInterval(timer); for (const c of conns) c.terminate(); for (const r of rooms.values()) clearTimeout(r.hostGoneTimer); },
  };
}

export function createSignalServer(opts) {
  const signal = createSignal(opts);
  const server = http.createServer((req, res) => {
    if (req.url === HEALTH) {
      res.writeHead(200, { 'content-type': 'application/json' });
      return res.end(JSON.stringify({ ok: true, rooms: signal.rooms.size }));
    }
    res.writeHead(404);
    res.end();
  });
  server.on('upgrade', (req, socket, head) => signal.handleUpgrade(req, socket, head));
  server.on('close', () => signal.stop());
  return server;
}
```

```js
// Pind og knapper fra alle kilder gøres ens: dødzone, klip til enhedscirklen, knapper som 0/1.
export const DEAD = 0.12;

export function normStick(x, y, dead = DEAD) {
  x = Number.isFinite(x) ? x : 0;
  y = Number.isFinite(y) ? y : 0;
  const len = Math.hypot(x, y);
  if (len <= dead) return { x: 0, y: 0 };
  const k = Math.min(1, (len - dead) / (1 - dead)) / len;
  return { x: x * k, y: y * k };
}

// En controllers besked {s, x, y, a, b} -> renset input, eller null for noget, der ikke er input.
export function parseInput(m) {
  if (!m || typeof m !== 'object' || !Number.isFinite(m.s)) return null;
  const { x, y } = normStick(Number(m.x), Number(m.y));
  return { s: m.s, x, y, a: m.a ? 1 : 0, b: m.b ? 1 : 0 };
}
```

```js
// Spillerlisten: telefoner, controllere og bots som ens spillere. Ren logik (test/players.test.js).
// Et spil læser kun player.input = { x, y, a, b, aPressed, bPressed }; aPressed er sand i præcis den frame, knappen
// gik ned -- også når den gik ned og op igen mellem to frames (latch).
export const COLORS = ['#ff4d5e', '#3fa7ff', '#ffd23f', '#3ddc84', '#b469ff', '#ff8c3a', '#2ee6d6', '#ff6fcf', '#a8e05f', '#f2f2f2'];
export const MAX_PLAYERS = 10;
export const STALE_MS = 1000;
const ZERO = { x: 0, y: 0, a: 0, b: 0 };

export function createRoster({ max = MAX_PLAYERS } = {}) {
  const list = [];
  const get = (id) => list.find((p) => p.id === id) ?? null;
  return {
    get size() { return list.length; },
    list: () => list,
    get,
    add({ id, name, source }, now = 0) {
      let p = get(id);
      if (p) {
        p.connected = true; p.goneAt = null; p.seen = now;
        if (name) p.name = name;
        return p;
      }
      if (list.length >= max) return null;
      const used = new Set(list.map((q) => q.color));
      p = {
        id, name, source, color: COLORS.find((c) => !used.has(c)),
        connected: true, lost: false, goneAt: null, ready: false,
        link: source === 'pad' ? 'pad' : source === 'bot' ? 'bot' : 'relay',
        input: { ...ZERO, aPressed: false, bPressed: false },
        raw: { ...ZERO }, seen: now, lastS: -Infinity, latchA: false, latchB: false,
      };
      list.push(p);
      return p;
    },
    remove(id) {
      const i = list.findIndex((p) => p.id === id);
      if (i >= 0) list.splice(i, 1);
    },
    setConnected(id, on, now = 0) {
      const p = get(id);
      if (!p) return;
      p.connected = on;
      p.goneAt = on ? null : now;
      if (!on) p.raw = { ...ZERO };
    },
    setLink(id, link) {
      const p = get(id);
      if (p) p.link = link;
    },
    setInput(id, inp, now = 0) {
      const p = get(id);
      if (!p || !inp) return false;
      if (inp.s !== undefined) {
        if (inp.s <= p.lastS) return false;
        p.lastS = inp.s;
      }
      if (inp.a && !p.raw.a) p.latchA = true;
      if (inp.b && !p.raw.b) p.latchB = true;
      p.raw = { x: inp.x, y: inp.y, a: inp.a, b: inp.b };
      p.seen = now;
      if (!p.connected) { p.connected = true; p.goneAt = null; }
      return true;
    },
    frame(now) {
      for (const p of list) {
        p.lost = p.source !== 'pad' && now - p.seen > STALE_MS;
        const r = p.lost ? ZERO : p.raw;
        p.input = { x: r.x, y: r.y, a: r.a, b: r.b, aPressed: p.latchA, bPressed: p.latchB };
        p.latchA = p.latchB = false;
      }
    },
    // Kun i lobbyen: telefoner/bots, der ikke er hørt fra i ms, og controllere, der har været frakoblet i ms.
    prune(now, ms = 10_000) {
      for (let i = list.length - 1; i >= 0; i--) {
        const p = list[i];
        const gone = p.source === 'pad' ? !p.connected && now - p.goneAt > ms : now - p.seen > ms;
        if (gone) list.splice(i, 1);
      }
    },
  };
}
```

```js
// Bluetooth-controllere via Gamepad-API'et (højst 4 -- browserens loft). Standard-mapping: venstre pind eller d-pad,
// knap 0 = A, knap 1 = B. En controller er med, når den har trykket A i lobbyen.
import { normStick } from './normalize.js';

const on = (b, i) => (b[i]?.pressed ? 1 : 0);

export function readPad(gp) {
  const b = gp.buttons ?? [];
  let x = gp.axes?.[0] ?? 0, y = gp.axes?.[1] ?? 0;
  const dx = on(b, 15) - on(b, 14), dy = on(b, 13) - on(b, 12);
  if (dx || dy) { x = dx; y = dy; }
  const s = normStick(x, y);
  return { x: s.x, y: s.y, a: on(b, 0), b: on(b, 1) };
}

export function pollGamepads(roster, now, { allowJoin }) {
  const pads = navigator.getGamepads?.() ?? [];
  const seen = new Set();
  for (const gp of pads) {
    if (!gp || !gp.connected) continue;
    const id = `pad:${gp.index}`;
    seen.add(id);
    const inp = readPad(gp);
    if (!roster.get(id)) {
      if (!allowJoin || !inp.a) continue;
      const p = roster.add({ id, name: `Controller ${gp.index + 1}`, source: 'pad' }, now);
      if (!p) continue;
      p.raw.a = 1;                               // trykket, der tilmeldte, er ikke også "klar"
    }
    roster.setInput(id, inp, now);
  }
  for (const p of roster.list()) {
    if (p.source === 'pad' && p.connected && !seen.has(p.id)) roster.setConnected(p.id, false, now);
  }
}
```

```js
const active = (players) => players.filter((p) => p.connected);

export function canStart(game, players) {
  const n = active(players).length;
  return n >= game.minPlayers && n <= game.maxPlayers;
}

export function lobbyStep(lobby, players, dt) {
  let changed = false;
  for (const p of players) {
    if (p.input.aPressed) p.ready = !p.ready;
    const dir = p.input.x > 0.6 ? 1 : p.input.x < -0.6 ? -1 : 0;
    if (dir && dir !== p.navDir) {
      lobby.sel = (lobby.sel + dir + lobby.games.length) % lobby.games.length;
      changed = true;
    }
    p.navDir = dir;
  }
  if (changed) for (const p of players) p.ready = false;
  const game = lobby.games[lobby.sel];
  const ready = canStart(game, players) && active(players).every((p) => p.ready);
  if (!ready) { lobby.countdown = null; return null; }
  lobby.countdown = lobby.countdown === null ? START_DELAY : lobby.countdown - dt;
  if (lobby.countdown > 1e-9) return null;
  lobby.countdown = null;
  return game;
}
```

```js
// Fast tilfældighed (?seed=N): mulberry32.
export function mulberry32(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

```js
// Isflagen: dyr, der glider, skubber og falder i vandet. Ren logik uden three.js (test/sumo-physics.test.js).
// Koordinater: x mod højre, z mod kameraet (pindens y), meter og sekunder. face: retningen (sin face, cos face).
export const R0 = 6;              // flagens radius ved start
export const BODY = 0.55;         // dyrenes radius
export const SHRINK_AFTER = 20;   // sekunder, før isen begynder at smelte
const SHRINK_RATE = 0.1, R_MIN = 2.4;
const ACC = 9, DRAG = 0.9, VMAX = 6.5;
const DASH = 7, DASH_T = 0.25, PUSH_CD = 1.2, PUSH_BONUS = 5;
const RESTITUTION = 0.8, GRAVITY = 14, BLAME_S = 3;

export function arenaRadius(t) {
  return t <= SHRINK_AFTER ? R0 : Math.max(R_MIN, R0 - (t - SHRINK_AFTER) * SHRINK_RATE);
}

export function createWorld(ids, rng = Math.random) {
  const n = ids.length, r = n === 1 ? 0 : R0 * 0.6, off = rng() * Math.PI * 2;
  return {
    t: 0,
    radius: R0,
    animals: ids.map((id, i) => {
      const ang = off + (i / n) * Math.PI * 2, x = Math.cos(ang) * r, z = Math.sin(ang) * r;
      return { id, x, z, y: 0, vx: 0, vz: 0, vy: 0, face: Math.atan2(-x, -z), alive: true, cd: 0, dash: 0, mass: 1, lastHit: null };
    }),
  };
}

export function step(w, inputs, dt) {
  const ev = [];
  w.t += dt;
  w.radius = arenaRadius(w.t);
  for (const a of w.animals) {
    if (!a.alive) {
      if (a.y > -4) { a.vy -= GRAVITY * dt; a.y += a.vy * dt; a.x += a.vx * dt; a.z += a.vz * dt; a.vx *= 0.97; a.vz *= 0.97; }
      continue;
    }
    const inp = inputs.get(a.id);
    const ix = inp?.x ?? 0, iy = inp?.y ?? 0;
    a.cd = Math.max(0, a.cd - dt);
    a.dash = Math.max(0, a.dash - dt);
    a.vx += ix * ACC * dt;
    a.vz += iy * ACC * dt;
    const k = Math.exp(-DRAG * dt);
    a.vx *= k; a.vz *= k;
    const sp = Math.hypot(a.vx, a.vz);
    if (sp > VMAX && a.dash === 0) { a.vx *= VMAX / sp; a.vz *= VMAX / sp; }
    if (Math.hypot(ix, iy) > 0.2) a.face = Math.atan2(ix, iy);
    if (inp?.aPressed && a.cd === 0) {
      a.vx += Math.sin(a.face) * DASH;
      a.vz += Math.cos(a.face) * DASH;
      a.cd = PUSH_CD;
      a.dash = DASH_T;
      ev.push({ type: 'push', id: a.id });
    }
    a.x += a.vx * dt;
    a.z += a.vz * dt;
  }
  collide(w, ev);
  for (const a of w.animals) {
    if (a.alive && Math.hypot(a.x, a.z) > w.radius) {
      a.alive = false;
      a.vy = 2;
      const by = a.lastHit && w.t - a.lastHit.t < BLAME_S ? a.lastHit.by : null;
      ev.push({ type: 'fall', id: a.id, by });
    }
  }
  return ev;
}

function collide(w, ev) {
  const live = w.animals.filter((a) => a.alive);
  for (let i = 0; i < live.length; i++) {
    for (let j = i + 1; j < live.length; j++) {
      const a = live[i], b = live[j];
      const dx = b.x - a.x, dz = b.z - a.z, d = Math.hypot(dx, dz);
      if (d >= BODY * 2) continue;
      const nx = d < 1e-6 ? 1 : dx / d, nz = d < 1e-6 ? 0 : dz / d;   // samme sted: skilles langs x
      const half = (BODY * 2 - d) / 2;
      a.x -= nx * half; a.z -= nz * half;
      b.x += nx * half; b.z += nz * half;
      const rel = (b.vx - a.vx) * nx + (b.vz - a.vz) * nz;           // < 0: på vej mod hinanden
      if (rel >= 0) continue;
      const imp = -(1 + RESTITUTION) * rel / (1 / a.mass + 1 / b.mass);
      a.vx -= imp * nx / a.mass; a.vz -= imp * nz / a.mass;
      b.vx += imp * nx / b.mass; b.vz += imp * nz / b.mass;
      if (a.dash > 0) { b.vx += nx * PUSH_BONUS; b.vz += nz * PUSH_BONUS; a.dash = 0; }
      if (b.dash > 0) { a.vx -= nx * PUSH_BONUS; a.vz -= nz * PUSH_BONUS; b.dash = 0; }
      a.lastHit = { by: b.id, t: w.t };
      b.lastHit = { by: a.id, t: w.t };
      ev.push({ type: 'hit', a: a.id, b: b.id, strength: -rel });
    }
  }
}
```

```js
// Runderne: nedtælling, kamp, rundevinder, først til 3. Ren logik (test/sumo-rules.test.js).
export const COUNTDOWN = 3, ROUND_END = 3, TARGET = 3;

export function createMatch(ids, { target = TARGET } = {}) {
  return {
    ids, target, round: 1, phase: 'countdown', t: COUNTDOWN, winner: null, roundWinner: null,
    scores: Object.fromEntries(ids.map((id) => [id, 0])),
  };
}

// alive: id'erne på flagen. Returnerer faseskiftet ('start' | 'round' | 'next' | 'match') eller null.
export function updateMatch(m, alive, dt) {
  if (m.phase === 'countdown') {
    m.t -= dt;
    if (m.t > 1e-9) return null;
    m.phase = 'play';
    return 'start';
  }
  if (m.phase === 'play') {
    if (alive.length > 1) return null;
    m.roundWinner = alive[0] ?? null;
    if (m.roundWinner !== null) m.scores[m.roundWinner]++;
    const champ = m.ids.find((id) => m.scores[id] >= m.target);
    if (champ) { m.phase = 'over'; m.winner = champ; return 'match'; }
    m.phase = 'roundEnd';
    m.t = ROUND_END;
    return 'round';
  }
  if (m.phase === 'roundEnd') {
    m.t -= dt;
    if (m.t > 1e-9) return null;
    m.round++;
    m.phase = 'countdown';
    m.t = COUNTDOWN;
    return 'next';
  }
  return null;
}

export function ranking(m) {
  return [...m.ids].sort((a, b) => m.scores[b] - m.scores[a] || (b === m.winner) - (a === m.winner));
}
```

```js
// En bot på isflagen (?bots=N): ind mod midten ved kanten, ellers efter den nærmeste og skub, når den er tæt på.
export function botInput(w, id, rng = Math.random) {
  const me = w.animals.find((a) => a.id === id);
  if (!me || !me.alive) return { x: 0, y: 0, a: 0 };
  const r = Math.hypot(me.x, me.z);
  if (r > w.radius * 0.72) return { x: -me.x / r, y: -me.z / r, a: 0 };
  let best = null, bd = Infinity;
  for (const o of w.animals) {
    if (o === me || !o.alive) continue;
    const d = Math.hypot(o.x - me.x, o.z - me.z);
    if (d < bd) { bd = d; best = o; }
  }
  if (!best || bd < 1e-6) return { x: 0, y: 0, a: 0 };
  return { x: (best.x - me.x) / bd, y: (best.z - me.z) / bd, a: bd < 1.8 && rng() < 0.08 ? 1 : 0 };
}
```

```js
export class SignalClient {
  constructor(url, handlers) {
    this.url = url;
    this.h = handlers;
    this.delay = 1000;
    this.stopped = false;
    this.connect();
  }

  connect() {
    if (this.stopped) return;
    const ws = this.ws = new WebSocket(this.url);
    ws.onopen = () => { this.delay = 1000; this.h.open?.(); };
    ws.onmessage = (e) => {
      let m;
      try { m = JSON.parse(e.data); } catch { return; }
      this.h.message?.(m);
    };
    ws.onclose = () => {
```

```js
// Konsollens side af netværket: én RTCPeerConnection pr. controller (konsollen tilbyder), kanalerne 'in' (uordnet,
// ingen gentagelser: kun det nyeste input tæller) og 'ctl' (pålidelig). Input tages imod fra både datakanal og
// server-reserve; løbenummeret i spillerlisten fjerner dubletter. Ingen STUN/TURN: alle er på samme wifi.
import { SignalClient } from './signal-client.js';

export class HostNet {
  constructor({ url, code = null, onRoom, onStatus, onJoin, onLeave, onInput, onLink }) {
    this.cb = { onRoom, onStatus, onJoin, onLeave, onInput, onLink };
    this.code = code;
    this.links = new Map();
    this.sig = new SignalClient(url, {
      open: () => { this.sig.send(this.code ? { t: 'host', code: this.code } : { t: 'host' }); onStatus('online'); },
      close: () => onStatus('offline'),
      message: (m) => this.onMessage(m),
    });
  }

  onMessage(m) {
    if (m.t === 'room') { this.code = m.code; this.cb.onRoom(m.code); }
    else if (m.t === 'peer-join') { this.cb.onJoin(m.peer, { pid: m.pid, name: m.name }); this.offer(m.peer); }
    else if (m.t === 'peer-leave') { this.drop(m.peer); this.cb.onLeave(m.peer); }
    else if (m.t === 'signal') this.onSignal(m.from, m.data);
    else if (m.t === 'relay') {
      const d = m.data;
      if (d?.k === 'in') this.cb.onInput(m.from, d.m);
      else if (d?.k === 'reoffer' && !this.direct(m.from)) this.offer(m.from);
    } else if (m.t === 'error') this.cb.onStatus(`error:${m.error}`);
  }

  direct(peer) { return this.links.get(peer)?.inCh.readyState === 'open'; }

  async offer(peer) {
    this.drop(peer);
    if (typeof RTCPeerConnection === 'undefined') return;
    const pc = new RTCPeerConnection({ iceServers: [] });
    const link = {
      pc,
      inCh: pc.createDataChannel('in', { ordered: false, maxRetransmits: 0 }),
      ctlCh: pc.createDataChannel('ctl'),
      pending: [],
    };
    this.links.set(peer, link);
    link.inCh.onmessage = (e) => { try { this.cb.onInput(peer, JSON.parse(e.data)); } catch { /* affald */ } };
    const changed = () => { if (this.links.get(peer) === link) this.cb.onLink(peer, this.direct(peer) ? 'direct' : 'relay'); };
    link.inCh.onopen = changed;
    link.inCh.onclose = changed;
    pc.onicecandidate = (e) => { if (e.candidate) this.sig.send({ t: 'signal', to: peer, data: { cand: e.candidate.toJSON() } }); };
    try {
      await pc.setLocalDescription(await pc.createOffer());
      this.sig.send({ t: 'signal', to: peer, data: { sdp: pc.localDescription.toJSON() } });
    } catch (e) { console.warn('webrtc offer', e); }
    changed();
  }

  async onSignal(peer, d) {
    const link = this.links.get(peer);
    if (!link || !d) return;
    try {
      if (d.sdp?.type === 'answer') {
        await link.pc.setRemoteDescription(d.sdp);
        for (const c of link.pending.splice(0)) await link.pc.addIceCandidate(c).catch(() => {});
      } else if (d.cand) {
        if (link.pc.remoteDescription) await link.pc.addIceCandidate(d.cand).catch(() => {});
        else link.pending.push(d.cand);
      }
    } catch (e) { console.warn('webrtc signal', e); }
  }

  drop(peer) {
    const l = this.links.get(peer);
    if (!l) return;
    this.links.delete(peer);
    l.pc.close();
  }

  send(peer, msg) {
    const l = this.links.get(peer);
    if (l?.ctlCh.readyState === 'open') l.ctlCh.send(JSON.stringify(msg));
    else this.sig.send({ t: 'relay', to: peer, data: { k: 'ctl', m: msg } });
  }
}
```

```js
// serveren (reserve). Er der ingen direkte forbindelse, beder den konsollen om et nyt tilbud hvert 10. sekund.
import { SignalClient } from './signal-client.js';

export class PadNet {
  constructor({ url, code, name, pid, noRtc = false, onState, onCtl }) {
    Object.assign(this, { noRtc, onState, onCtl });
    this.pc = null; this.inCh = null; this.ctlCh = null; this.pending = [];
    this.joined = false; this.hostHere = false;
    this.sig = new SignalClient(url, {
      open: () => this.sig.send({ t: 'join', code, name, pid }),
      message: (m) => this.onMessage(m),
      close: () => { this.joined = false; this.dropRtc(); onState('connecting'); },
    });
    onState('connecting');
    this.retry = setInterval(() => {
      if (this.joined && this.hostHere && !this.noRtc && !this.direct) this.sig.send({ t: 'relay', data: { k: 'reoffer' } });
    }, 10_000);
  }

  get direct() { return this.inCh?.readyState === 'open'; }

  report() { this.onState(this.direct ? 'direct' : this.hostHere ? 'relay' : 'waiting-host'); }

  onMessage(m) {
    if (m.t === 'joined') { this.joined = true; this.hostHere = m.host; this.report(); }
    else if (m.t === 'error') this.onState({ error: m.error });
    else if (m.t === 'host-gone') { this.hostHere = false; this.dropRtc(); this.report(); }
    else if (m.t === 'host-back') { this.hostHere = true; this.report(); }
    else if (m.t === 'signal') this.onSignal(m.data);
    else if (m.t === 'relay' && m.data?.k === 'ctl') this.onCtl(m.data.m);
  }

  async onSignal(d) {
    if (this.noRtc || !d || typeof RTCPeerConnection === 'undefined') return;
    try {
      if (d.sdp?.type === 'offer') {
        this.dropRtc();
        const pc = this.pc = new RTCPeerConnection({ iceServers: [] });
        pc.onicecandidate = (e) => { if (e.candidate) this.sig.send({ t: 'signal', data: { cand: e.candidate.toJSON() } }); };
        pc.ondatachannel = (e) => this.channel(e.channel);
        pc.onconnectionstatechange = () => {
          if (this.pc === pc && (pc.connectionState === 'failed' || pc.connectionState === 'closed')) { this.dropRtc(); this.report(); }
        };
        await pc.setRemoteDescription(d.sdp);
        for (const c of this.pending.splice(0)) await pc.addIceCandidate(c).catch(() => {});
        await pc.setLocalDescription(await pc.createAnswer());
        this.sig.send({ t: 'signal', data: { sdp: pc.localDescription.toJSON() } });
      } else if (d.cand) {
        if (this.pc?.remoteDescription) await this.pc.addIceCandidate(d.cand).catch(() => {});
        else this.pending.push(d.cand);
      }
    } catch (e) { console.warn('webrtc', e); }
  }

  channel(ch) {
    if (ch.label === 'in') this.inCh = ch;
    else if (ch.label === 'ctl') {
      this.ctlCh = ch;
      ch.onmessage = (e) => { try { this.onCtl(JSON.parse(e.data)); } catch { /* affald */ } };
    }
    ch.onopen = () => this.report();
    ch.onclose = () => this.report();
  }

  dropRtc() {
    this.pc?.close();
    this.pc = this.inCh = this.ctlCh = null;
    this.pending = [];
  }

  sendInput(m) {
    if (this.direct) this.inCh.send(JSON.stringify(m));
    else if (this.joined && this.hostHere) this.sig.send({ t: 'relay', data: { k: 'in', m } });
  }

  stop() { clearInterval(this.retry); this.dropRtc(); this.sig.stop(); }
}
```

```js
function env(g, t, peak, dur) {
  g.gain.setValueAtTime(0.0001, t);
  g.gain.exponentialRampToValueAtTime(peak, t + 0.01);
  g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
}

function tone(freq, dur, { type = 'sine', peak = 0.3, at = 0, to = null } = {}) {
  if (!ctx) return;
  const t = ctx.currentTime + at, o = ctx.createOscillator(), g = ctx.createGain();
  o.type = type;
  o.frequency.setValueAtTime(freq, t);
  if (to) o.frequency.exponentialRampToValueAtTime(to, t + dur);
  env(g, t, peak, dur);
  o.connect(g).connect(master);
  o.start(t);
  o.stop(t + dur + 0.05);
}

function hiss(dur, { freq = 1500, to = null, q = 1, peak = 0.3, at = 0, type = 'bandpass' } = {}) {
  if (!ctx) return;

  f.frequency.setValueAtTime(freq, t);
  if (to) f.frequency.exponentialRampToValueAtTime(to, t + dur);
  env(g, t, peak, dur);
  s.connect(f).connect(g).connect(master);
  s.start(t, Math.random() * 0.5);
  s.stop(t + dur + 0.05);
}
```

```js
  floe.receiveShadow = true;
  scene.add(floe);

  players.forEach((p, i) => {
    const root = new THREE.Group(), body = new THREE.Group();

    root.add(body);
    const ring = new THREE.Mesh(new THREE.RingGeometry(BODY * 0.9, BODY * 1.15, 32),

    root.add(ring);
    const tag = nameSprite(p.name, p.color);
    tag.position.y = 2.0;
    root.add(tag);
    scene.add(root);
    actors.set(p.id, { root, body, ring, tag });

      floe.position.y = -0.35 + Math.sin(time * 0.8) * 0.03;

        o.geometry?.dispose();
        for (const m of [].concat(o.material ?? [])) { m.map?.dispose(); m.dispose(); }
```

```js
// Sumo på isflagen: 2-10 dyr, pinden glider, A skubber, sidste dyr på flagen vinder runden, først til 3.
import { createWorld, step, SHRINK_AFTER } from './physics.js';
import { createMatch, updateMatch, ranking } from './rules.js';
import { botInput } from './ai.js';
import { createView } from './view.js';

export default {
  id: 'sumo',
  title: 'Sumo på isflagen',
  emoji: '🐧',
  how: 'pind: glid · A: skub',
  minPlayers: 2,
  maxPlayers: 10,
  start(ctx) {
    const players = ctx.players.map((p) => ({ id: p.id, name: p.name, color: p.color }));
    const ids = players.map((p) => p.id), info = new Map(players.map((p) => [p.id, p]));
    const view = createView(players);
    const match = createMatch(ids);
    let world = createWorld(ids, ctx.rng), time = 0, lastCount = null, overT = null, warned = false;
    const name = (id) => info.get(id)?.name ?? '?';
    const pips = (id) => '●'.repeat(match.scores[id]) + '○'.repeat(match.target - match.scores[id]);
    const tellAll = (text) => ids.forEach((id) => ctx.notify(id, { t: 'state', text, score: pips(id) }));

    function onEvent(e) {
      if (e.type === 'push') ctx.audio.whoosh();
      else if (e.type === 'hit') {
        ctx.audio.thud(e.strength);
        if (e.strength > 4) { ctx.notify(e.a, { t: 'buzz', ms: 40 }); ctx.notify(e.b, { t: 'buzz', ms: 60 }); }
      } else if (e.type === 'fall') {
        ctx.audio.splash();
        ctx.notify(e.id, { t: 'buzz', ms: 350 });
        ctx.notify(e.id, { t: 'state', text: 'Plask! Du er i vandet', score: pips(e.id) });
        ctx.hud.tick(e.by ? `${name(e.by)} skubbede ${name(e.id)} i vandet` : `${name(e.id)} faldt i vandet`);
      }
    }

    function onPhase(change) {
      if (change === 'start') {
        ctx.audio.whistle(); ctx.audio.say('go');
        ctx.hud.center(''); ctx.hud.banner('SKUB!');
        tellAll('Skub!');
        warned = false;
      } else if (change === 'round') {
        const w = match.roundWinner;
        ctx.hud.banner(w ? `${name(w)} vinder runden!` : 'Uafgjort!', `Runde ${match.round}`);
        if (w) ctx.audio.fanfare();
        ctx.audio.say('round');
        tellAll(w ? `${name(w)} vandt runden` : 'Uafgjort');
      } else if (change === 'next') {
        world = createWorld(ids, ctx.rng);
        lastCount = null;
      } else if (change === 'match') {
        ctx.hud.banner(`${name(match.winner)} vinder!`, `Først til ${match.target}`);
        ctx.audio.fanfare(); ctx.audio.say('winner');
        tellAll(`${name(match.winner)} vandt!`);
        ctx.notify(match.winner, { t: 'buzz', ms: 500 });
        overT = 4;
      }
    }

    tellAll('Gør dig klar …');
    return {
      done: null,
      bot: (id) => botInput(world, id, ctx.rng),
      update(dt, live) {
        time += dt;
        if (match.phase === 'countdown') {
          const n = Math.ceil(match.t);
          if (n !== lastCount) { lastCount = n; ctx.hud.center(String(n)); ctx.audio.blip(); ctx.audio.say(`count-${n}`); }
        } else {
          const inputs = new Map();
          for (const p of live) if (info.has(p.id)) inputs.set(p.id, p.input);
          for (const e of step(world, inputs, dt)) onEvent(e);
          if (!warned && match.phase === 'play' && world.t > SHRINK_AFTER - 2) { warned = true; ctx.hud.banner('Isen smelter!'); }
        }
        const change = updateMatch(match, world.animals.filter((a) => a.alive).map((a) => a.id), dt);
        if (change) onPhase(change);
        if (overT !== null && (overT -= dt) <= 0 && !this.done) {
          this.done = { ranking: ranking(match).map((id) => ({ ...info.get(id), score: match.scores[id] })) };
        }
        ctx.hud.scores(players.map((p) => ({
          name: p.name, color: p.color, score: match.scores[p.id], of: match.target,
          out: !world.animals.find((a) => a.id === p.id)?.alive,
        })));
      },
      render(renderer) { view.sync(world, time); renderer.render(view.scene, view.camera); },
      dispose() { ctx.hud.clear(); view.dispose(); },
    };
  },
};
```
